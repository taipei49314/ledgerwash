## Publication boundary

The accepted manifest digest must bind the separately inspected EC receipt to
the exact wheel and sdist uploaded as release assets. The manual publication
workflow downloads and verifies those bytes; it does not rebuild them or
independently query private EC evidence. PyPI Trusted Publishing is bound to
`taipei49314/ledgerwash`, `pypi-publish.yml`, environment `pypi`.
That environment permits only Branch `main` and no tags.

The installation check covers one EC Windows runtime. The original
suite includes frozen PR2 baseline controls; candidate imports must come from
the installed wheel. Neither cross-platform wheel installation nor reproducible
build equality is claimed. Completed bounded downloads and available failure
records are retained; interrupted or oversized downloads may fail before their
bytes are saved.
